# 資科萬事通：804 題測試包（整理版）

這是**測試題目規劃**，不是已執行的 benchmark，也不是模型訓練資料。

## 交給誰、拿什麼

- 自己檢查：`資科萬事通_804題正式測試規劃.xlsx`，先讀「閱讀說明」「實驗對照」，再看「題目分配」。
- Codex 程式匯入：`資科萬事通_804題測試分配.jsonl`。
- 需要通用格式可改用同名 `.csv`。

## 已處理

- 804 題均保留原文、原類型、順序和原始行號，每題有 Q0001～Q0804 唯一 ID。
- 一題可以進多項實驗，**不是平均切割 804 題**。
- A1/A2-1/A2-2 需共用一套 FAQ gold 評估題；A0/A4-1/A4-2/A5 需共用一套 RAG 題。
- Semantic Cache 的題型包含重複、改寫、不同意圖；必須安排先後順序和 cache warm，不能直接逐題獨立執行來算命中率。
- Speculative Decoding 只需要固定生成子集，且保持 Target/Prompt/設定相同。
- Topic Identification 主要用多輪題，但群組與逐輪正確主題須先確認。
- 最後的整合實驗，只比較真正完成而且相容的算法。

## 尚須人工核對

1. 有 160 題被暫分為 40 個四輪**候選**群組，並非已驗證真實對話切分。
2. 另 18 題沒有可靠群組；不能直接用來計算多輪主題辨識準確率。
3. 題目只有問句和類型；本版未將任何猜測填為標準答案、來源或意圖 ID。可逐題實際推論與計時，但要量化正確性須先取得可靠標註。
4. 某些單輪「資訊不足」問題在提供上下文後可能可回答；是否拒答需考慮原始測試情境。
5. 在執行最終測試前檢查訓練資料/測試題庫重疊，且不可拿這 804 題調整訓練、threshold、模型選擇。
